# Junteng Liu's Homepage
**Personal homepage of Junteng Liu, a PhD candidate in Computer Science at the Hong Kong University of Science and Technology.**

![Academic Pages template example](images/themes/homepage-light.png "Academic Pages template example")

This site is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) GitHub Pages template, which was forked (then detached) by [Stuart Geiger](https://github.com/staeiou) from the [Minimal Mistakes Jekyll Theme](https://mmistakes.github.io/minimal-mistakes/), which is © 2016 Michael Rose and released under the MIT License (see LICENSE.md).

Site content is managed in this repository:
- Site-wide configuration: `_config.yml`
- Page content and publications: `_pages/`, `_publications/`
- Header navigation: `_data/navigation.yml`

To run the site locally:

```bash
git clone https://github.com/rodeospita/LJT-Homepage.git
cd LJT-Homepage
bundle install
bundle exec jekyll serve -l -H localhost
```

The site will be served at [http://localhost:4000](http://localhost:4000).
